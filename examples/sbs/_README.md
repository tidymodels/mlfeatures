# R ↔ Python side-by-sides

The `*.html` files here are **committed, generated output**. `_build.py` holds
the six hand-authored specs (condensed R + Python code, difference notes) and
renders them into line-matched two-pane pages. After editing a spec:

    python examples/sbs/_build.py

then commit the regenerated HTML together with the spec change. The R panes
quote verbatim R code and real run results produced in the shoez-research repo
— they cannot be regenerated by CI, only re-rendered.
